# Softscent - Project Setup

This is an ASP.NET Core web application.

## Prerequisites

- [.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## How to Run

### Visual Studio Code

1. Open the folder in VS Code.
2. Press `F5` or go to **Run and Debug** and click the green play button to start debugging.
3. The application will launch in your default browser.

### Command Line

1. Open a terminal in the project folder.
2. Run the following command:
   ```bash
   dotnet run
   ```

### Visual Studio (IDE)

1. Open `Softscent.sln` in Visual Studio.
2. Press `F5` or click **IIS Express** / **Softscent** to run the project.

## Project Structure

- **Controllers**: MVC controllers handling request logic.
- **Views**: UI pages (Razor views).
- **Models**: Data models.
- **wwwroot**: Static assets (CSS, JS, images).
